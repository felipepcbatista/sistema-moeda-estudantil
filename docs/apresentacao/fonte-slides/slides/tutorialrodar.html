#ComandoO que acontece
1docker compose up -dPostgreSQL na porta 5434 e Mailpit em :8025
2mvn spring-boot:runFlyway cria o schema e a carga inicial; API em :8080
3npm install && npm run devFront em :5180, repassando /api ao back-end
4node scripts/popular-demo.mjsAlunos, empresas, vantagens e transações pela própria API
5mvn test28 testes, sem precisar de Docker

Fonte: README, seção 14 (Como executar) · 16/18

Como qualquer pessoa sobe o sistema a partir do repositório. O Docker Compose sobe o banco e o servidor de email de teste. O back-end, ao subir, roda as migrações do Flyway, então o banco nunca é criado à mão. O front sobe com o Vite. O script de demonstração cria os dados pela própria API, com o token de cada ator, então os dados de exemplo passam pelas mesmas regras de negócio e de segurança de um usuário real. E os 28 testes rodam sem Docker, num banco em memória que executa as mesmas migrações.
