Início do tutorial das tecnologias, que o enunciado pede para a apresentação final. A ideia é mostrar o papel de cada peça neste projeto, não a ferramenta em abstrato. Front em React com Vite: o servidor do Vite repassa as chamadas para a API, então o navegador vê uma única origem e não precisamos configurar CORS. Back-end em Spring Boot com Java 21. Persistência com Spring Data JPA e Flyway. PostgreSQL rodando no Docker, e H2 nos testes. Segurança com Spring Security e JWT. Email com JavaMailSender, e em desenvolvimento o Mailpit, que captura os emails numa caixa de entrada local. Nos próximos três slides, como cada parte se usa.
