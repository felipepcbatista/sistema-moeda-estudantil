Slide de contraponto: não fizemos só escolhas boas, e cada uma tem preço. JWT sem estado é simples, mas não dá para invalidar um token antes de ele expirar. Mitigamos com validade curta, e em produção usaríamos uma lista de tokens revogados. Usar H2 nos testes deixou os testes rápidos, mas escondeu um bug de tipo de coluna que só apareceu no PostgreSQL real. Desde então, todo fluxo é validado também no banco real. A regra de que o professor só reconhece alunos da própria instituição é uma hipótese nossa: queremos validar com a professora. E tirar a listagem geral protege dados pessoais, mas deixa o sistema sem tela de administração.
