Demonstração ao vivo, cerca de cinco minutos. Antes da aula: subir o Docker, o back-end e o front, e rodar o script de demonstração. A tela de login tem atalhos para uma conta de cada perfil. Seguir a ordem da tabela, que conta a história de uma moeda: a professora reconhece, o aluno é avisado por email, troca por uma vantagem, e a empresa confere o código. Fechar mostrando a segurança: com um token inválido, o sistema devolve para o login. Plano B, se algo falhar ao vivo: mostrar os testes rodando com mvn test.
